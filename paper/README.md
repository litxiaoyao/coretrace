# Paper source

Figures1–3 are editable manuscript diagrams generated by `draw_figures.py`.
They and the drawing code live under `paper/`, separately from the releasable
data-result plotting code in `scripts/figures.py`. Each diagram is made from
native PowerPoint shapes, text and connectors. Example questions, evidence,
and responses come from completed formal predictions; `figures/figure_sources.json`
records their exact source.

```bash
python draw_figures.py --pdf --libreoffice /path/to/soffice
```

The drawing helper uses `python-pptx==1.0.2`. Outputs are individual
`figures/figure1.pptx`–`figure3.pptx`, the combined `figures1-3.pptx`, and
converted PDFs. Final captions and placement will be integrated with the full
manuscript after the formal experiments finish. Pending causal-effect sizes
are not filled into these diagrams.

`related_work.tex` contains two concise paragraphs: multi-hop reasoning and
mechanisms of factual information processing. It cites only work directly
relevant to the research question. `references.bib` contains the nine cited
references. The supplied reference papers guide the presentation; they are not
a mandatory citation list. `main.tex` is an anonymous section preview.

## Template

Checked on **2026-11-08**: the [ICML 2027 author instructions](https://icml.cc/Conferences/2027/AuthorInstructions)
say that instructions will be published with the Call for Papers. An official
2027 style package was not available there. This preview therefore uses the
**2026** style under its original name, as authorized; it is not an ICML 2027
template.

Official source: [ICML 2026 author instructions](https://icml.cc/Conferences/2026/AuthorInstructions)
and the linked [style archive](https://media.icml.cc/Conferences/ICML2026/Styles/icml2026.zip).
The media server could not be reached from this machine during preparation.
The included `icml2026.sty` and `icml2026.bst` were downloaded without modification
from the [public template mirror](https://github.com/kaousheik-26/icml2026).
Their header identifies the 2026 style; equivalence to the currently served
official archive has not been independently established. Replace them with the
official archive before submission. When the 2027 package is released, update
the package and bibliography-style declarations in `main.tex`; the section
itself is independent of the style year.

With a normal LaTeX installation:

```bash
cd paper
latexmk -pdf main.tex
```

Or run `pdflatex main`, `bibtex main`, and `pdflatex main` twice. PDF compilation
requires a TeX toolchain. A temporary standalone Tectonic installation was also
used to compile this document during preparation, without modifying the research
conda environment. TeX build products belong outside version control.

Bibliographic metadata come from ACL Anthology, NeurIPS/ICLR proceedings, PMLR,
the AAAI publisher page and supplied paper, and author-deposited arXiv records.
Layer-Order Inversion is cited by its versioned arXiv record, without assigning
unverified proceedings metadata. No prior-paper numerical result is used as a
result of this project.
