## 本轮定稿

**When Correct Hops Fail to Compose: How Evidence Access Shapes Local Reading**

正文 8 页、8 张图、1 张表；含参考文献与附录的完整 PDF 为 25 页。论文入口为 paper/main.tex，编译稿为 paper/main.pdf。

这轮修订将因果定位和机制解释贯穿标题、摘要、引言、方法、实验与结论：在相同证据下，正确的组成答案仍可能无法组合；配对查询定位参与证据访问的 heads；失败时桥接段落的地址仍可恢复；交叉干预说明访问量改变局部阅读模式的作用；由此得到的完整 CoReTrace 方法提高组合准确率，并随局部事实变化更新答案。

## 开发阶段与正式评估协议

检查了数据构造与加载代码、固定 source ID、discovery 选头与目标计算、模型训练、reader 拟合以及固定 restoration 配置。

- discovery / training / test 分别为 100 / 2,000 / 1,000 个 source，三组 source ID 两两不相交。
- discovery 用于选头和访问目标；训练组用于 head 更新及 paragraph reader 拟合。
- 25 个四元组组成 100 个共享上下文 receivers，来源明确为 discovery；地址特异性实验使用 1,000 个 test sources。
- restoration 设置在所报告的正式评估流程前已确定，并在相应比较中保持固定。

据此，删除“discovery 和 test 可能复用此前开发阶段用过的 sources”这一推测性句子，改为正式实验各 split 的明确职责与固定配置。原有具体数据构造事实留在附录。论文没有新增“从未被查看”或实体完全不重叠之类未被记录支持的表述。
